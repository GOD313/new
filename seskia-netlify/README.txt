سایت دانلود سسکیا — آماده انتشار واقعی روی Netlify

اتصال مستقیم مخزن:
1) مخزن GOD313/new را در Netlify انتخاب کنید.
2) تنظیمات Build از فایل netlify.toml ریشه به‌صورت خودکار خوانده می‌شود.
3) نیازی به Build command نیست؛ Publish directory روی seskia-netlify تنظیم شده است.

انتشار دستی:
1) فقط پوشه seskia-netlify را ZIP کنید.
2) وارد https://app.netlify.com/drop شوید.
3) فایل ZIP را داخل صفحه رها کنید.

لینک دکمه دانلود، کپی لینک و QR یکسان است:
https://seskia.online/download.php

این مسیر HTTPS جایگزین لینک HTTP مستقیم IP شده تا دانلود از صفحه HTTPS نتلیفای به‌عنوان محتوای ناامن مسدود نشود.
برای تغییر آدرس دانلود در آینده، مقدار DOWNLOAD_URL در assets/app.js را عوض کنید و QR را نیز برای همان آدرس دوباره بسازید.
